# 🏨 Hostel Management System

A web-based Hostel Management System developed using Python, Flask, HTML, CSS, Bootstrap, and MySQL.

## 📌 Features

- 👤 Student registration and management
- 🏠 Room management
- 💰 Fee management
- 📋 Hostel records management
- 🔐 Login system
- 📊 Dashboard
- 🖼️ Student profile image upload
- 🗄️ MySQL database integration

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Bootstrap
- MySQL
- XAMPP
